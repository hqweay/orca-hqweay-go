# lets-block-nav

大纲导航插件 - 为 Orca Note 提供全局大纲树与沉浸式的全文检索引擎。

## 核心能力

- **全局大纲树**：根据当前块结构生成无缝的大纲树，极大方便长篇文档的阅读与跳转。
- **无感截断**：完美的文字展示体验，再窄的侧边栏也不会换行破坏排版，悬浮即可查看全文。
- **全文检索**：支持搜索与动态标签过滤（待办/已完成/标题）。
- **双轨同步检索**：首创的双引擎机制，无论是在侧边栏修改标题类型，还是在主编辑器内输入，检索结果 0 延迟实时同步。
- **防卸载保护**：跨面板操作时具有完美的虚拟列表卸载防御机制，保证各种转换与操作的绝对稳定性。

## 交互指南

- **左键点击**：编辑器平滑滚动定位到该节点（侧边栏保持大纲全局视图）。
- **Alt/Option + 左键**：编辑器下钻（Zoom In）至该节点。
- **右键点击**：呼出上下文菜单，支持快速在**标题**与**普通文本**间互相转换。
- **拖拽**：支持原生块的任意拖拽层级重组。

## 唤出方式

- 点击顶部工具栏的原生侧边栏切换按钮。
- 或在设置中配置**右侧显示**，甚至按住 `Shift` 点击按钮实现左右侧边栏镜像反转唤出。
