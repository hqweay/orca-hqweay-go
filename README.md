# 虎鲸笔记插件：恐龙工具箱

一个为 [Orca Note](https://orca.pet) 打造的增强插件集合。日常笔记里那些繁琐、重复的操作——排版、归档、回顾、发布、收集——这里都有对应的开箱即用工具。

**一句话**：不用切到别的软件，在虎鲸笔记里就能完成记笔记之外的大部分事。

## 安装与使用

1. 下载 Release 中的 `package.zip`。
2. 解压后，将整个文件夹复制到 Orca Note 的插件目录。
3. 在软件设置中刷新并启用插件。所有子功能均可在「插件设置」中单独开启或关闭。

## 功能一览

### 1. 📝 一键格式化 (Format Block)
解决中文排版问题：标点、空格、全半角一键规范化。
- 自动修正中英文标点
- 优化中英文混排空格
- 规范化全角 / 半角字符

### 2. 🎙️ VoiceNotes 同步
把 voicenotes.com 的录音笔记同步进虎鲸笔记，自动归档。
- 一键全量或增量同步
- 自动归档到专属收件箱

### 3. 📂 导入工具 (Import)
把已有资料搬进虎鲸笔记。
- 批量导入本地 Markdown 文件夹
- CSV 表格智能解析为笔记节点，可自动套用模板标签

### 4. 🧹 样式清除 (Remove Style)
快速清理富文本格式。
- 一键移除加粗、颜色等行内样式
- 链接转纯文本、删除空行
- 各种标题统一转为自动层级标题

### 5. 🔃 块排序 (Sort Blocks)
智能排序多个同级块。
- 支持创建多个自定义排序预设
- 通过上下箭头自由组合数十种块类型的排序优先级
- 单个预设时右键一键排序，多个预设自动变成子菜单

### 6. 📤 发布到 GitHub (Publish)
把笔记一键发布成博客文章。
- 自动提取并上传文中图片到图床
- 自动生成 Frontmatter 元数据

### 7. 🏪 插件市集 (Bazaar)
应用内的社区插件市场。
- 浏览、安装、更新、卸载社区插件
- 支持自定义第三方插件源

### 8. 🏷️ 快捷标签 (Quick Tag)
快捷键一键插入常用标签。
- 光标处即插即用
- 可自动附带状态、优先级等属性

### 9. 🌳 标题层级整理 (Heading Tree)
修复混乱的文档层级。
- 自动识别 H1–H4 标题，重组文档树
- 消除错误的阶梯式缩进，普通文本自动归属到最近的标题下

### 10. 🌐 网页助手 (Web Assistant)
把网页内容变成笔记。
- 内置沉浸式浏览器
- 智能提取网页元数据（如豆瓣图书、电影）
- 右键一键将网页内容转为 Markdown 剪藏

### 11. 🧠 记忆复习 (SRS)
基于 FSRS 算法的记忆工具，对抗遗忘。
- 问答与沉浸式阅读两种复习模式
- 为任意标签或查询结果开启复习漫游

### 12. 🪞 块嵌入子项增强 (Embed Children)
让镜像引用块自动展示子块内容。
- 随「用户脚本」模板库一键插入使用
- 可设置启动时自动加载，或从顶部栏等入口手动切换

### 13. 🎲 随机漫步 (Random Walk)
随机探索知识库，重温过去的知识片段。
- 自动抓取指定标签下的内容
- 无重复发牌，越翻越有惊喜

### 14. 📋 智能剪贴板注入 (Clipboard Injection)
外部 JSON 数据直接粘贴为原生笔记节点。
- 支持携带标签、属性
- 自动转存远程图片到本地

### 15. 🛠️ 块工具箱 (Block Tools)
常用块操作的快捷菜单。
- 子块一键归集到原引用源
- 父节点下置顶 / 置底
- 链接与引用格式快速互转

### 16. 🔒 隐私块 (Privacy Block)
一键把敏感内容藏起来。
- 视觉上有锁形提示
- 底层向 AI 隐藏隐私内容，不影响日常编辑

### 17. 🌊 块流转 (Block Flow)
右键把选中的块快速流转。
- 发送 / 移动 / 引用至今日、明日日志或全局收件箱

### 18. 📌 置顶块面板 (Pinned Blocks)
高频笔记打上特定标签即固定到侧边栏，随时唤回。

### 19. 🪐 Arc 侧边栏 (Arc Tabs)
媲美 Arc 浏览器的现代侧边栏。
- 多空间隔离、固定标签自由拖拽排序
- 自动记录去重今天的历史浏览
- 可在「更多」tab 查看最近访问，点击即跳转

### 20. 📥 全局收集箱 (Roam Sidebar)
复刻 Roam Research 的全局收集交互。
- 完全持久化的原生大纲块，跨页面随意拖拽收集
- 大纲折叠管理，状态永不丢失

### 21. 🔗 链接工具 (Link Tools)
链接的快捷转换。
- 右键超链接一键转为原生块引用
- 在图钉（📌）引用格式间灵活切换

### 22. 🌳 大纲导航树 (Block Nav)
侧边栏大纲导航，长文档也能快速定位。
- 点击平滑跳转、快捷下钻阅读
- 实时本地检索，结果瞬间过滤
- 底部按钮联动主编辑器，一键精准展开 / 折叠

### 23. 🔗 收集引用 (Gather Refs)
一键生成当前文档的反向引用汇总。
- 通过 `/gather` 或右键菜单触发
- 自动去重生成整洁的 MOC 目录树

### 24. 🧊 编辑器层级折叠 (Editor Fold)
保持工作区整洁。
- 「展开至此同级」右键菜单
- 支持快捷键绑定的全局命令，自动截断深层结构展示

### 25. 🕸️ 局部关系图谱 (Local Graph)
侧边栏实时关系图谱，跟随你的足迹生长。
- 动态渲染当前活动块的邻居网络
- 快捷过滤标签、层级关系与常规引用
- 右键边缘节点定向拓展 / 折叠，物理阻尼防抖动
- 回放探索模式：足迹按时序重播，相机自动跟随

### 26. 🖼️ 嵌入视图 (Embed View)
在笔记里嵌入网页、HTML 或 Twitter/X 内容。
- 拖拽调整嵌入区域高度
- 网址嵌入自动显示图标与域名，登录状态不丢失

### 27. 📜 用户脚本 (User Scripts)
给代码块打上 `#脚本` 标签，代码立刻变成可注入的脚本 / 样式，深度定制你的 Orca。
- **注入即用** — CSS 自动生效、JS 自动执行，点击即可加载 / 卸载，刷新自动清理
- **多种入口** — 右键菜单、顶部栏、编辑器侧边栏、AI 菜单、全局快捷键，可同时绑定多个
- **侧边栏挂件** — 脚本能在「更多」tab 注册自定义挂件（如番茄钟）或启动器条目，支持文件夹分组
- **接收块拖拽** — 挂件可设为笔记块的投放目标，拖入即处理
- **模板库** — 内置块嵌入子项、快捷打标签、粘贴选中文本为块引用、侧边栏布局、番茄钟、暂存箱、AI 知识熔炉等模板，一键插入、开箱即用

### 28. 🤖 AI 助手 (AI)
选中文本，用 AI 解释、翻译、润色、打标签或执行自定义指令。
- **开箱即用** — 内置「解释含义 / 润色 / 翻译 / 打标签」，无需任何配置
- **打标签** — 根据选中内容给目标块打上简洁准确的标签；跨块选中时，每一个被选中的块都会打上相同标签
- **自定义动作** — 在指定标签的块里写提示词即注册一个新动作；名字、图标在属性面板改，不用写代码
- **流式预览** — 生成过程实时显示在可拖拽的浮动面板，支持 Markdown、公式与代码高亮
- **结构化插入** — 结果以「分组头 + 子内容」插入，自动附上选中的原文引用
- **工具调用即时可见** — 模型调用 MCP 工具（如写入今日日志）后，界面自动刷新，写入结果无需手动刷新即可看到
- **与用户脚本联动** — 勾选 `aiMenu` 的脚本会出现在 AI 菜单中，实现「选中即跳转 / 查询」

### 29. ⏱️ 时间统计 (Time Log)
给带时间属性的标签打点，自动聚合成时间线与统计。
- **多视图** — 日 / 周 / 月时间线，加上统计页（总时长、日均、连续、时段 / 年分布、月报），支持全屏展开
- **无结束自动推断** — 同一标签一天内的相邻打点自动连成一段；可配置相邻上限与「今日实时」统计，粗粒度打点也能获得准确概览
- **仅时间点** — 只配置开始时间的标签组（如碎碎念）在时间线上以彩色圆点标记，悬停查看内容与时间、点击跳转，不计入时长
- **月视图点组圆点** — 仅时间点组在月历格子里同样以彩色圆点标记（最多 4 个，超出折叠为 +N）
- **目标进度** — 可为标签组设置每日 / 每周 / 每月目标时长，日 / 周 / 月视图顶部显示进度条；月视图达成每日目标的日子标 ✓
- **范围过滤与缩放** — 右键框选 ≥2 小时设自定义范围过滤；左侧缩放滑轨竖直拖拽 / 滚轮缩放，双击或一键清除回到自适应
- **专注与环比** — 统计页新增「专注」指标（≥45 分钟连续记录占比）与「环比上月」卡片（总时长、活跃天数、分组增量）
- **AI 分析** — 一键让 AI 基于当月统计快照生成文字洞察（统计概览与当月记录文本发送给已配置的 AI 提供商）
- **AI 图表** — 让 AI 生成内联 SVG 统计图表；分析与图表产物持久化为列表，每条可单独删除
- **图例开关** — 各组可在图例里点击隐藏，只影响展示不影响数据
- **统计页导航** — 年分布上移至统计页顶部作「选月导航」（点击月柱切换、当前月高亮），下方即所选月份的报表；周规律标注「全年平均」与月口径区分
- **按时长 / 按块数** — 统计页顶部一键切换统计口径：看「每类事花了多久」选时长，看「记了多少内容」选块数；整页图表跟随切换并记住你的选择
- **左键打点 / 安排** — 在时间线空白处左键单击记录时刻（打点），按住左键上下拖动按起止安排一段（范围，≥2 分钟）。安排在未来时间会自动带上提醒标记；打点用的默认标签可在设置里指定或只记提醒
- **日历界面补记数据 (Backfill)** — 漏记了？直接在日历的过去时刻左键打点 / 拖拽安排，会弹出「补标记」浮层让你选记到哪个标签组（点记点组、段记时长组），选中即写入当天日记，时间线、统计即时更新 —— 再也不用翻回当天手写补录
- **创建记录写入干净** — 打点 / 安排出的新记录文本只带 `#标签` 尾巴（与编辑器内一致），时间属性挂在标签上而非写进文本，之后在编辑器里随意改内容都不影响时间数据
- **提醒计划 (Reminder)** — 未来安排的记录以虚线计划条 / 计划点显示在时间线上，预览接下来一整天的安排；时刻已过的提醒不再出现、不进统计
- **创建即定位** — 打点 / 安排出的记录会自动定位（已在当前页面就滚动过去，否则跳转），方便立刻改内容；左键点击记录也是智能定位
- **创建可撤销** — 新记录创建后弹出的通知可一键撤销删除；新记录即时出现在当日日记里
- **拖拽调整时间段** — 直接拖时间条就能改：拖中部整体移动，拖上缘改开始、下缘改结束（仅时长段）；未来计划段不可拖。改动即时生效，通知可一键撤销

## 开发说明

模块化架构，每个功能独立成 `src/lets-*` 目录，由 `main.tsx` 动态加载启用的子插件。
