# Fix: Embed View ChildrenJsx Circular Error

## Problem
`childrenJsx={childrenJsx}` in `EmbedViewRenderer.tsx` causes circular error when inserting child blocks.

## Root Cause
`BlockChildren` receives the `block` object directly, which might contain circular references when child blocks reference the parent.

## Solution
Clone the block object before passing to `BlockChildren` to break circular references.

## Files to Modify
- `src/lets-embed-view/components/EmbedViewRenderer.tsx` (lines 336-346)

## Change
```tsx
// Before (causes circular error)
const childrenJsx = useMemo(
  () => (
    <BlockChildren
      block={block as any}
      panelId={panelId}
      blockLevel={blockLevel}
      indentLevel={indentLevel}
    />
  ),
  [block, panelId, blockLevel, indentLevel],
);

// After (clone block to break circular reference)
const childrenJsx = useMemo(
  () => (
    <BlockChildren
      block={{ ...block } as any}
      panelId={panelId}
      blockLevel={blockLevel}
      indentLevel={indentLevel}
    />
  ),
  [block, panelId, blockLevel, indentLevel],
);
```

## Verification
1. Type check: `npx tsc --noEmit`
2. Test: Create embed block, insert child blocks
3. Verify: No circular error, child blocks work correctly
