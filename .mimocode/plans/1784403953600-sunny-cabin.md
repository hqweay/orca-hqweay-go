# Change default block insertion position to bottom

## Goal
When dragging a block from the editor into the sidebar, append it to the bottom instead of the top.

## Change
**File:** `src/lets-roam-sidebar/utils/state.ts:90`

Change `unshift` to `push`:
```typescript
// Before
tab.stackedBlocks.unshift({ id: blockId, collapsed: false });

// After
tab.stackedBlocks.push({ id: blockId, collapsed: false });
```

## Verification
- Type check: `npx tsc --noEmit`
- Manual: drag a block into sidebar, it should appear at the bottom
- Manual: drag a block between two existing blocks, insertion line should work as before
